# Tulasi Men's PG Website

Static HTML, CSS and vanilla JavaScript build based on `RK_NILAYAM_Website_Development_Phases.pdf`.

## Current Status

- Built the requested project foundation.
- Added Krishna-inspired loading animation.
- Added navigation, hero, about, facilities, rooms, life, gallery, food, safety, location, FAQ, contact CTA and footer.
- Added mobile sticky CTA, responsive layouts, SEO tags, structured data, sitemap and robots file.
- Added real property photos from `assets/images` and kept one generated placeholder for any missing categories.
- Availability and room-price enquiries open WhatsApp with a pre-filled message, including the selected sharing option.
- Facilities include a TV in every room and a vast bike parking area.
- The PG offers a homely environment, AC and non-AC room options, and provides mattresses and pillows.
- Separate luggage wardrobes will be provided for every resident.
- Added verified room details for private, 2-share, 3-share and 4-share non-AC options, including deposits, refund amounts, notice period and included furnishings.
- Added a maintainable nearby-places guide in `js/nearby.js` with category filters and Google Maps direction links. The list intentionally uses verified location relationships and addresses instead of unsupported distance or travel-time claims.
